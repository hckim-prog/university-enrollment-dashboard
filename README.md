# 대학 재적학생 트렌드

대학알리미의 학과별 재적 학생 현황을 통합해 재학생·휴학생·재적학생 변화를 탐색하는 한국어 로컬 대시보드입니다. 2단계에서는 검증된 2023~2025년을 최초 게시 버전으로 이관하고, 관리자 XLSX 업로드·검증·차이 비교·게시·복구 기능을 추가했습니다. 로그인, Supabase, 클라우드 데이터베이스와 인터넷 배포는 아직 제외합니다.

## 구현 화면

- 전체 현황: 재학생·재적학생·휴학생 KPI, 전년 대비 인원·증감률, 연도·지역·계열 차트
- 학과 트렌드: 학과군 시장 흐름, 학교별 개별 학과 추세 유형, 공시 신설·폐과와 비교상 신규·이탈, 사분면과 기여 학교 드릴다운
- 학교 비교: 학교별 재학생·재적학생 규모와 전년 대비 증감
- 상세 데이터: 정규화된 학과 행 20개씩 탐색 및 페이지 이동
- 공통 필터: 연도, 지역, 학교, 설립구분, 계열, 학과상태, 학과명
- 학과 분석 기준: 학과군, 추세 유형, 최소 전년도 학생 수, 최소 증감 인원·증감률, 재학생·재적학생, 비교 기간, 폐과 포함 여부
- 반응형 UI: 데스크톱 사이드바와 모바일 메뉴·접이식 필터
- 데이터 관리: XLSX 업로드, 게시 차단 오류·경고, 버전 이력, 원자적 게시와 이전 버전 복구

## 실행

요구 환경은 Node.js 20 이상과 pnpm입니다.

```powershell
pnpm install
pnpm data:migrate -- --input-dir "C:\Users\user\Downloads\data_20260731153427"
pnpm data:store:validate
pnpm dev
```

브라우저에서 [http://127.0.0.1:3000](http://127.0.0.1:3000)을 엽니다.

프로덕션 빌드로 실행하려면 다음 명령을 사용합니다.

```powershell
pnpm build
pnpm start
```

## 데이터 위치와 보안 범위

원본 XLSX는 `public/`에 복사하지 않습니다. 최초 이관과 웹 업로드 원본은 Git에서 제외된 `data/local-store/originals`에 안전한 내부 이름으로 보관하며 서버만 접근합니다. 원래 파일명·크기·SHA-256·기준연도는 감사 메타데이터에 기록됩니다.

- 정규화 데이터: `data/processed/enrollment.json`
- 검산 보고서: `data/processed/validation-report.json`
- 변환·계산 명세: `data/processed/methodology.json`
- 전용 변환기: `scripts/convert-enrollment.ts`
- 독립 재검산: `scripts/validate-enrollment.ts`
- 비공개 버전 저장소: `data/local-store/` (`.gitignore` 적용)
- 최초 이관: `scripts/migrate-local-data.ts`
- 게시 저장소 검산: `scripts/validate-local-store.ts`

관리자 업로드, 오류와 경고, 새·과거 연도 추가, 기존 연도 교체, 게시·복구, 백업과 Supabase 이전 방법은 [로컬 데이터 관리 운영 가이드](docs/local-data-management.md)에 정리했습니다.

## 원본 데이터 갱신

새 XLSX 3개가 있는 폴더를 `--input-dir`로 지정합니다. 파일 이름은 `2023년 ...학과별자료.xlsx`, `2024년 ...학과별자료.xlsx`, `2025년 ...학과별자료.xlsx` 형식이어야 합니다.

```powershell
pnpm data:convert -- --input-dir "C:\원본\폴더"
pnpm data:validate
pnpm data:store:validate
pnpm test
pnpm build
```

변환기는 원본을 읽기만 하며 수정하거나 이동하지 않습니다. 결과 파일은 `data/processed/`에 다시 생성됩니다.

## 전용 변환 방식

대학알리미 XLSX 세 파일은 워크시트의 사용 범위가 실제 데이터 크기와 달리 `A1`로 기록되어 있습니다. 따라서 일반적인 사용 범위 판독에 의존하지 않고 ZIP 내부의 `sharedStrings.xml`, `Sheet1.xml`, `mergeCell` 범위를 직접 SAX 방식으로 읽습니다.

- 병합 셀: 좌상단 값을 실제 병합 범위에만 복원해 학교(F), 단과대학(G), 학과(H), 주야(I)를 복구
- 2023·2024년: 37열(A:AK), 재학생 `N+O`, 휴학생 `T+U`, 유예학생 `Z+AA`, 재적학생 `AF+AG`
- 2025년: 41열(A:AO), 추가된 소계 열 `N`, `U`, `AB`, `AI`를 사용하고 정원내·외 및 남녀 합계와 교차 검산
- 모든 연도: `재적학생 = 재학생 + 휴학생 + 학사학위취득유예학생`

각 변환 행은 원본 행 번호인 `sourceRow`를 보존합니다. 원본 파일별 SHA-256, 열 수, 변환 행 수, 병합 복원 수, 오류 수는 검산 보고서에 기록됩니다.

- 중복 차원 행
- 음수값
- 정원내·외 및 남녀 소계
- 재적학생 계산식
- 필수 차원 누락
- 연도별 열 수

## 학과 트렌드 방법론

학과군 규칙은 `src/config/department-groups.json` 한 파일에서 우선순위·포함/제외 키워드·수동 예외·설명을 관리합니다. 한 행은 대표 학과군 하나에만 배정되며 애매한 이름은 `기타·미분류`로 남깁니다.

2025년 기본 재적학생 기준 22개 대표 학과군이 재적학생의 92.8%, 학과 관측의 89.9%를 분류합니다. 학생 규모 증가는 취업 전망이나 미래 유망성을 의미하지 않습니다. 정확 비교 키, 추세 유형, 기여도, 신설·폐과와 비교상 신규·이탈의 차이, 새 규칙 추가 방법은 [학과 트렌드 분석 방법론](docs/department-trend-methodology.md)에서 확인할 수 있습니다.
