# 대학 시장 분석 방법론

이 문서는 시장 분석 화면의 지표 정의, 계산식, 해석 범위와 검산 방법을 설명합니다. 분석 단위는 대학알리미 학과별 행을 학교·대학구분·지역·표준분류 계열 등으로 합산한 값입니다.

## 1. 분석 기준

- 분석 시작연도: 사용자가 선택한 장기 비교의 시작점
- 분석 종료연도: 현재 현황과 상세 데이터를 표시하는 기준연도
- 전년: 분석 종료연도 바로 이전 연도
- 시장 지표: 재적학생 또는 재학생
- 학교 단위: 학교코드 + 본분교
- 학과 비교키: 학교코드 + 본분교 + 학과코드 + 주야 + 학과특성

기본 분석 기간은 2019~2025년입니다. 빠른 선택은 전체 기간, 최근 3년(2023~2025), 최근 1년(2024~2025)을 제공하며 직접 시작·종료연도를 선택할 수 있습니다. 전 화면의 KPI, 차트와 순위는 같은 시작·종료연도와 공통 필터를 사용하고 상세 데이터는 종료연도 행만 표시합니다. 선택 기간 밖의 연도는 추세와 장기 계산에서 제외합니다.

## 2. 핵심 지표

### 시장 규모

선택한 지표를 기준연도, 필터 조건 안에서 모두 더합니다.

```text
시장 규모 = Σ 학과 행의 재적학생 또는 재학생
전년 증감 = 기준연도 시장 규모 - 전년 시장 규모
전년 증감률 = 전년 증감 ÷ 전년 시장 규모
```

전년 값이 0이거나 없으면 증감률을 계산하지 않습니다.

### 장기 변화

```text
장기 변화율 = (기준연도 값 - 시작연도 값) ÷ 시작연도 값
```

시작연도 값이 0이거나 없으면 변화율을 계산하지 않습니다. 전년 변화율 절댓값이 0.05% 미만이면 화면에는 `보합`으로 표시하되 정확한 증감 인원은 유지합니다.

### 활동 학교와 학과

재적학생이 1명 이상인 학교코드+본분교를 활동 학교로, 같은 조건의 학과 비교키를 활동 학과로 계산합니다. 0명 행은 원본 보존과 이력 확인에는 사용하지만 활동 수에는 포함하지 않습니다.

## 3. 시장 구성과 지역 변화

### 점유율

```text
세그먼트 점유율 = 세그먼트 학생 수 ÷ 전체 학생 수
```

대학구분, 지역, 대계열, 중계열, 소계열과 학교에 같은 정의를 적용합니다.

### 지역별 장기 비교

지역별 학생 수는 선택한 지표와 공통 필터를 적용한 뒤 지역 단위로 합산합니다. 화면은 종료연도 규모 상위 10개 지역의 시작연도와 종료연도 학생 수를 나란히 비교합니다. 연도별 작은 움직임보다 전체 기간의 규모 차이를 읽는 데 초점을 둡니다.

## 4. 전공 분류

- 대계열: 인문사회, 공학, 자연과학, 예체능, 의학, 광역 등 가장 큰 분류
- 중계열: 대계열 아래의 전공 분야
- 소계열: 가장 세부적인 표준분류

화면은 대계열부터 시작해 항목을 선택할 때마다 중계열과 소계열로 내려갑니다. 각 단계에서 현재 학생 수, 전체 비중, 시작연도 대비 증감 인원을 함께 표시합니다.

## 5. 비교 가능성과 주의사항

1. 2019~2022와 2023~2025 원본은 학과 행 구성 방식이 다릅니다. 원본 행 수를 장기 시장 지표로 비교하지 않고 학생 수 합계를 사용합니다.
2. 2025년부터 광역계열이 관측되어 일부 대계열 점유율 변화에는 분류 변경 효과가 포함될 수 있습니다.
3. 학생 수 변화는 공시 결과의 기술 통계입니다. 교재 채택·판매량, 향후 수요, 교육 품질이나 취업성과를 뜻하지 않습니다.
4. 작은 분류는 증감률 변동이 커질 수 있으므로 절대 인원, 시작 규모와 점유율을 함께 봅니다.

## 6. 차트 맵

| 화면 | 질문 | 차트 | 핵심 필드 |
|---|---|---|---|
| 대학시장 요약 | 현재 큰 전공 분야는 어디인가 | 가로 막대 | 대계열, 학생 수, 점유율, 장기 증감 |
| 대학시장 요약 | 대학·전문대학 규모는 어떤가 | 비교 목록 | 대학구분, 학생 수, 점유율, 장기 증감 |
| 전공 시장 | 큰 계열과 세부 계열의 규모는 | 계층형 비교 목록 | 대·중·소계열, 학생 수, 점유율, 장기 증감 |
| 전공 시장 | 장기 증가·감소 분야는 어디인가 | 순위 목록 | 대·중·소계열, 장기 증감 인원과 증감률 |
| 지역·학교 | 지역별 장기 규모는 어떻게 달라졌나 | 시작·종료연도 그룹 막대 | 지역, 시작연도 학생 수, 종료연도 학생 수 |
| 지역·학교 | 어느 지역·학교가 움직였나 | 순위형 막대 | 지역·학교, 학생 수, 증감 |

모든 절대 규모 막대는 0을 기준으로 하며, 증감은 부호와 정확한 인원을 함께 표시합니다.

## 7. 검산

시장 분석 API는 응답마다 다음을 확인합니다.

- 대계열 합계 = 선택 시장 전체 합계
- 대학·전문대학 합계 = 선택 시장 전체 합계
- 모든 현재 행에서 재적학생 산식 일치
- 선택 연도 이후 데이터가 추세에서 제외됨

원본 단계의 중복·음수·필수 차원·남녀 소계·재적학생 산식 검사는 `scripts/validate-enrollment.ts`에서 독립적으로 다시 실행합니다.
