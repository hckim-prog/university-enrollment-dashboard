# 과목별 시장 탐색 개선

외부 API 없이 기존 2023~2026년 교육과정과 연결 학생 자료를 재사용한다. 원본·학생 수·연결 키는 변경하지 않았다. 운영 배포는 하지 않았다.

## 사용 순서

1. **시장 흐름**에서 주제를 입력한다. 쉼표로 구분한 검색어는 OR 조건이며 공백은 그대로 문구로 검색한다. 이름이나 코드를 자동 병합하지 않는다.
2. 공통 확보 학교 / 각 연도 전체 학교를 선택한다. 관련 학교·학과·교육과정 등록·연결 재학생 추세와 표를 확인하고 CSV로 내린다.
3. **과목 검색**에서 학교·학과·이수구분을 좁힌다. 선택 목록은 검색 적용 없이 갱신된다. 목표 학교·학과 목록은 재학생·관련 등록 건수·학교명으로 정렬하여 상위 30학과를 보여준다.
4. 과목 후보를 저장한다. 검색 변경 및 화면 재진입에도 브라우저 저장소에 유지되며, 후보별 선택 당시 조건·데이터 버전을 CSV에 보존한다. 학생 합계는 연도별로 분리한다. 다른 포트·브라우저·기기에는 공유되지 않는다.
5. **연도별 교육과정 비교**에서 처음 관측·미관측·변경·해설 변경·이수구분 변경·검토 필요·동일을 선택한다. 변경과 해설/이수구분 변경 건수는 겹칠 수 있다. 관측 결과와 불명확한 연결의 검토 표시는 구분한다.

## 해석 기준

- 공통 학교는 검색 주제와 무관하게 모든 확보 연도에 교육과정 자료가 있는 학교코드와 학교 유형의 교집합이다. 동일 학과 패널은 아니다. 학과 개편·차수·수록 범위 차이는 남는다.
- 학과 재학생은 해당 연도 복합 학과 키로 중복 제거한다. 미연결은 0으로 바꾸지 않는다.
- 처음 관측·미관측은 실제 신설·폐강을 확정하지 않는다. 같은 학과에서 새 과목명과 사라진 과목명이 함께 보이면 두 항목을 유지하고 검토 표시한다.
- 동일 키 복수 등록과 학과명 변경은 해설·이수구분 변화를 확정하지 않고 검토 대상으로 남긴다.
- 검색은 부분 문자열 검색이며 `AI` 같은 짧은 영문 검색어는 다른 단어의 일부도 찾을 수 있다.

## 기술 및 검증

- 원본 전체를 브라우저에 보내지 않고 서버에서 연도별 압축 JSONL을 순차로 읽는다. 추세는 학교별 학과 집계만 보관한다.
- 약 1MB의 `curriculum-catalog.json.gz`는 선택 목록 전용 파생 데이터다. 빌드 전에 버전을 확인하고 필요할 때만 재생성한다. 버전이 다르거나 없으면 서버는 정규화 자료로 목록을 재구성한다.
- 조회 캐시는 버전·조건별로 제한하며 비교 유형/페이지 변경은 동일 비교 결과를 재사용한다. 처음 주제를 분석할 때는 여러 연도를 읽으므로 대기 시간이 있다.
- TypeScript, ESLint, 단위 테스트 40개, 프로덕션 빌드 통과. 빌드의 기존 Google 폰트 다운로드는 네트워크 접근을 허용한 재실행에서 성공했다.
- `scripts/verify-curriculum-improvements.ts`: 실제 인공지능 연도별 기준값, 공통 학교 범위, 선택 목록, 그룹 합계, 복수 검색, 비교 필터 검사.
- `scripts/verify-curriculum-api.ts`: 기존 학생 API, 2026 전체 집계, 가천대/전문대 표본, 미연결·빈 검색, 잘못된 연도, 원본 근거 검사.
- 브라우저에서 가천대 선택 후 91개 학과 옵션 자동 갱신, 인공지능1·2 선택 시 1학과 63명 집계, 화면 재진입 후 후보 유지, 실제 CSV 다운로드와 코드/조건/버전 보존을 확인했다. 해설 변경 필터에서 실제 변경 항목을 확인했다.

실제 인공지능 전체 자료의 교육과정 등록은 2023년 2,145건 → 2026년 2,992건이다. 공통 확보 학교는 403개이며, 이 범위의 관련 학교는 252개 → 261개, 등록은 2,137건 → 2,966건이다. 각 연도의 확보 범위를 고정했는지에 따라 수치가 달라진다.

로컬 빌드 확인: `pnpm build` 후 `pnpm start --hostname 127.0.0.1 --port 3101`. 개발 서버는 `pnpm dev --port 3100`으로 실행한다.
