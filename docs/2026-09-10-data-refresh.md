## 4. 교육과정 연결과 해석

처음에 가천대·가톨릭관동대·가톨릭대의 연도별 표본을 확인한 후 전체 변환했다. 연결키는 **조사년도=기준연도 + 대학구분 + 학교코드 + 본분교 + 학과코드 + 주야 + 학과특성**이다. 코드는 문자열로 유지한다. 이름 유사도로 합치지 않는다. 학생 자료에서 같은 학과명에 다른 코드가 관측되거나 본분교·주야·특성이 다르면 검토로 표시한다.

## 5. 화면 및 로컬 확인

```powershell
pnpm dev --port 3100
```

`http://127.0.0.1:3100` → **과목별 시장 탐색**.

주제·과목명, 해설 포함 옵션, 연도, 대학구분, 학교, 학과, 이수구분을 설정하고 ‘검색 적용’을 누른다. 최초 검색 후 학교 목록을 선택할 수 있으며, 학교 선택 후 다시 검색하면 해당 학교의 학과 목록이 제공된다. 조건은 결과 위에 표시된다. 새 검색 적용 시 후보 선택이 초기화되고 같은 검색의 페이지 이동에서는 유지된다.

과목을 선택하면 선택된 학과의 중복 없는 재학생 합계가 표시된다. ‘선택 후보 CSV 내려받기’는 UTF-8 BOM, 과목·해설·학점·이수구분·학생 수·연결상태·양쪽 원본 파일/시트/행/SHA256·검색조건·데이터버전을 포함한다. 코드의 앞자리 0을 보존하기 위해 CSV 코드 셀은 명시적 텍스트 접두사를 사용한다. CSV를 Excel로 가져올 때 학교·학과코드 열을 텍스트로 지정하면 된다. 수식 시작 문자는 실행되지 않도록 처리한다.

연도별 비교는 기본 2025→2026이며 실제 확보된 연도만 선택 가능하다. ‘이전·비교연도 해설과 원본 보기’에서 양쪽 해설과 출처를 대조한다. 검색은 처음 약 10초, 전체 연도 비교는 약 20~30초가 걸릴 수 있다. 동일 검색 결과는 서버의 제한된 캐시를 사용한다.

원본 전체를 메모리에 올리지 않는다. XLSX 공유 문자열은 임시 SQLite 디스크 인덱스(`output/data-refresh/shared/`)로 조회하고 시트는 행 단위로 처리한다. 이는 변환 전용 임시 저장소이며 앱의 데이터베이스가 아니다. 앱은 기존 패턴을 따라 연도별 gzip JSONL을 서버에서 순차 검색한다. 비교 시 긴 해설 대신 해시를 보유하고 원문은 요청한 항목만 다시 조회한다.
